## 원칙 (원본 요약)

- 기존 Figma의 **컬러 · 타이포 · 콘텐츠는 유지**하고, 내비게이션 · 시트 · 버튼 · 안전 영역만 iOS 26 기준으로 다시 설계한다.
- 기기: iPhone 16 Pro 402×874 · 상단 안전 영역 62 · 하단 34. 다크 테마만.
- 탭: 홈 · 릴레이 · 커뮤니티 · 마이 + 검색. 기본은 iOS 26 플로팅 글래스(4탭 캡슐 + 분리된 원형 검색 버튼), 클래식 5탭 변형도 있다.
- 앱바 대신 콘텐츠 위에 뜬 44pt 글래스 원형 버튼(뒤로 · 공유 · 더보기). 스와이프로 뒤로 가기를 전제한다.
- 모달: 큰 시트 + 손잡이. 등록 · 완료는 내비게이션 바 오른쪽에 둔다. 액션 시트 · 공유 시트 · Alert는 iOS 관례를 따른다.
- 터치 영역 44pt 이상, 12px 미만 글자 금지, 위험 동작은 #FF453A.
- 로딩은 스피너가 아니라 스켈레톤으로 보여 준다. 빈 상태는 「왜 비었는지 + 다음에 할 일」을 한 문장씩 쓰고 버튼 하나를 둔다(10f).
- 재미 장치(8차)의 경쟁은 「적당히」로 하고, 보상은 칭호 · 배지 · 명함 테마 같은 꾸미기 요소로만 준다.
- 정책 문구(약관 · 탈퇴 · 이용 제한)는 **제안**이며 법무 검토가 필요하다(7차 명시).

## 원본 안의 지시 · 기준

- 「투표 방식은 3b · 3c로 대체」(1c 헤더) → 릴레이 투표의 기준은 3b · 3c다.
- 「차트 탭을 릴레이로 바꿈」(10차) → 탭 기준은 10a다.
- 「9a · 9b는 1b와 비교해 고르시면 됩니다」 → 홈 시안은 아직 고르지 않았다.
- 11차 「남은 후보 · 결정이 먼저 필요함」: 가사 보기(Apple Music API는 가사를 주지 않음 → 메뉴에서 빼기 권장) · 공유 링크 웹 미리보기 · 칭호 · 시즌 보상 연출 · 이벤트 참여 상세 · 앱 실행 화면.
- 캔버스에서 AI에게 내리는 지시문은 발견되지 않았다.
