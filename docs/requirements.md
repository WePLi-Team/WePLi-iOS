# 요구사항 (REQ)

기획 원본(Claude Design — `docs/design/README.md`)에서 옮긴 기능 요구다. 화면 세부(배치 · 색 · 문구)는 원본이 기준이고, 여기에는 ID · 한 줄 요약 · 근거만 둔다. 원본 파일 약칭은 차수 번호다(예: `5` = `WePLi 5 New Screens.dc.html`).
상태: 미착수 · 진행 중 · 일부 구현 · 완료 · 보류(결정 필요)
